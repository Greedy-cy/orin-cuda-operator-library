# Attention v6：FP16 WMMA QK/PV，FP32 online 状态

## 1. 新的数据类型口径

v6 开始独立 FP16 路线：Q/K/V global/shared 为 FP16；QK/PV Tensor Core 累加、
score scale、maximum、sum、alpha、online output state 和最终输出均为 FP32；当前
probability tile 为 FP16。

CPU reference 会先把输入量化到 FP16，再用 double 计算 attention，因此误差不
包含“原始 FP32 输入对比 FP16 kernel”的口径偏差。阈值为
`abs_error <= 2e-2 + 2e-2*abs(reference)`。v6 与 FP32 v5 的耗时只描述端到端
dtype+kernel 演进，不能冒充同精度加速或尚未测量的 FP16 cuDNN 比例。

## 2. kernel 结构

一个 256-thread block 处理 BM=16、BN=16：

1. Q/K/V tile 加载到 shared；
2. warp 0 循环 D/16 次 WMMA，得到 16x16 FP32 QK；
3. 16 个线程逐行更新 FP32 online maximum/sum，并把本 tile probability 转为 FP16；
4. 对旧 FP32 O state 乘 alpha；
5. D/16 个 warps 分别用 WMMA 计算 `P(16x16)*V(16x16)`；
6. FP32 PV 加入 O state，全部 K tiles 完成后执行 O/l。

causal 只扫描到 query block 需要的最后一个 key tile，并在对角 tile 逐行 mask。
D=64/128 且 S%16=0 使用 WMMA；其他尺寸走 FP16 input、FP32 compute scalar
online fallback。

## 3. 正确性

| 路径/形状 | causal | extreme | 最大绝对误差 | 结果 |
|---|---:|---:|---:|---|
| WMMA `B1,H2,S32,D64` | 0 | 0 | `2.71e-5` | PASS |
| fallback `B1,H2,S37,D71` | 1 | 0 | `5.96e-8` | PASS |
| WMMA `B1,H2,S64,D128` | 0 | 1 | `8.20e-5` | PASS |
| WMMA `B1,H8,S128,D64` | 0 | 0 | `1.84e-5` | PASS |
| WMMA `B1,H8,S128,D128` | 1 | 0 | `7.01e-5` | PASS |

接近零的参考元素会把最大相对误差放大到十以上，因此判定包含绝对项；最大绝对
误差仍比 0.02 小两个数量级。extreme 输入同样稳定。

## 4. sanitizer 与资源

WMMA `B1,H1,S32,D128,causal=1`：memcheck 0 errors、racecheck 0 hazards、
synccheck 0 errors，CPU double reference PASS。fallback `S37,D71` memcheck 0
errors。

ptxas：WMMA 47 registers/thread、0 spill、1 barrier；fallback 40 registers、0
spill。dynamic shared 为 D64 16,064 bytes、D128 30,400 bytes。

## 6. Nsight Systems / Compute

`B1,H8,S128,D128,non-causal`：nsys 单 kernel median `0.239184 ms`。NCU：

| 指标 | v6 |
|---|---:|
| Duration | 269.54 us |
| Compute / Memory throughput | 49.16% / 59.67% |
| Issue slots busy / No eligible warp | 50.01% / 49.97% |
| Warp cycles/instruction | 16.57 |
| Active threads/warp | 31.13 |
| Registers/thread | 47 |
| Achieved occupancy | 68.65%（理论 83.33%） |
| Executed instructions | 3,995,648 |

关键证据：shared loads 平均 **4-way bank conflict**（4,719,977 conflicts），stores
平均 **2-way**（1,873,559 conflicts）；655,872 excessive shared wavefronts 约占
59%。CTA barrier stall 平均 6.0 cycles，占 warp 指令间隔约 **36.1%**。

根因一是 WMMA/shared 矩阵使用紧凑 16/64/128 leading dimension，二是 QK 阶段
只有 warp0 工作，其他 warps 在 barrier 等待。

## 7. v7 假设

v7 做两个由 NCU 支持的改变：

1. Q/K/V/P leading dimension 增加 8 half padding，FP32 score/O/PV 使用非 32-bank
   整齐 stride；
2. 由 D/16 个 warps 各计算一个 K 维 partial QK WMMA，再并行归并 score。

v7 同时固化 D64/D128 和 causal tile skip，但不叠加 cp.async，先确认 shared 布局
与 warp 负载均衡的独立收益。
