# GEMM v5：cp.async 异步双缓冲

## 1. 从 v4 到 v5

v4 把下一 tile 先加载到通用寄存器，计算后再写入另一 shared buffer；虽然获得约
2% 小收益，但 global load 的结果仍需占用寄存器并等待后续 shared store。v5 用
Ampere `cp.async.cg.shared.global` 完成每线程两次 16-byte 搬运：

```text
global memory ──cp.async──> shared buffer
```

流水协议如下：

1. prologue 发出 tile 0，`commit_group`；
2. 每轮先向备用 buffer 发出下一 tile 并 commit；
3. `wait_group<1>` 只保证当前组完成，允许下一组继续在飞；
4. `__syncthreads()` 后计算当前 buffer；
5. 再同步，保证旧 buffer 读取完成后才在下一轮覆盖；
6. 最后一轮用 `wait_group<0>` 排空异步组。

对齐条件仍为 `M%64==0, N%64==0, K%16==0`。非对齐形状使用标量 fallback，
避免给 cp.async 路径加入复杂的 partial-copy 判断。tile、每线程 `4×4` 累加和
float4 写回均与 v4 相同。

## 2. 环境与测量口径

| 项目 | 值 |
|---|---|

| CUDA / cuBLAS | 12.6 / 12.6，cuBLAS pedantic FP32 |

非对齐小形状仍是大 tile 的弱项。它只用于验证回退路径，不用于宣称 cuBLAS
比例。

|---:|---|---:|---:|---:|---:|---|

| 512 | cp.async | 15.999936 ms | 1,073.746 GFLOP/s | 1.06× | 79.44% | PASS |

本版不会用单个 95.95% 结果代替完整形状结论。

## 7. Nsight Compute：异步搬运的收益来源

1024³ 稳态 kernel：

| 指标 | v4 | v5 | 变化/解释 |
|---|---:|---:|---|
| Duration | 2.15 ms | 2.02 ms | -6.0% |
| Roofline FP32 peak | 48% | 51% | +3 pp |
| Memory throughput | 88.16% | 80.97% | 等待隐藏后 L1/TEX 不再最先饱和 |
| Compute throughput | 61.99% | 65.89% | +3.90 pp |
| Issue slots busy | 62.18% | 65.97% | +3.79 pp |
| No eligible warp | 37.80% | 34.01% | -3.79 pp |
| Warp cycles / instruction | 12.47 | 11.76 | -5.7% |
| Executed instructions | 43,223,040 | 43,096,064 | 基本不变 |
| Registers / thread | 63 | 60 | -3，无 spill |
| Achieved occupancy | 64.62% | 64.69% | 基本不变 |

执行指令数量几乎不变，但 issue、eligible warp、compute throughput 和每指令周期
同时改善，符合 cp.async 让 global-to-shared 搬运与当前 tile FMA 重叠的假设。
这也是它与 v4 的关键区别：收益来自调度时序，而不是删掉大量指令。

NCU 新指出 shared access 存在 5,224,288 个 excessive wavefronts，估算局部改善
空间约 3.7%。这为 v6 的 tile/shared 布局候选提供证据；同时 60 registers/thread
仍把理论 occupancy 限制为 66.67%。

## 8. 下一步

v6 将 cp.async kernel 模板化并进行有限配置扫描，候选围绕两项证据设计：

- 扩大 BM/BN 或改变 thread tile，比较数据复用与寄存器 occupancy；
- 改变 BK/shared 形状，观察 shared wavefront 与流水深度。

扫描同时覆盖 4096³ 与 LLM M=128/512/1024，不根据单一方阵挑选参数。
M=1/16 继续记录，但需要不同算法映射，不强迫 regular-M kernel 兼顾。
