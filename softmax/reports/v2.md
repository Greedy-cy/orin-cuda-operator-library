# Softmax v2：float4 向量化与标量回退

## 1. 优化假设

v1 已将规约成本显著降低，并在主形状转为内存主导。v2 对 `cols % 4 == 0`
的行使用 128-bit `float4` 读取、写入和归一化，减少标量内存及循环指令；非 4
对齐行完整回退到 v1 的标量路径。

与 Reduce v4 不同，Softmax 每个元素还包含 max、exp、sum 和 normalize，减少
指令可能比保持多条独立标量 load 更重要，因此需要单独验证。

## 2. 正确性与性能

| Rows | Cols | v1 Median | v2 Median | 相对 v1 | v2 有效 I/O | 正确性 |
|---:|---:|---:|---:|---:|---:|---|
| 1 | 32 | 0.008512 ms | 0.008512 ms | 1.00× | 0.030075 GB/s | PASS |
| 1 | 1,024 | 0.009760 ms | 0.008192 ms | 1.19× | 1.000000 GB/s | PASS |
| 128 | 128 | 0.013504 ms | 0.013696 ms | 0.99× | 9.570093 GB/s | PASS |
| 128 | 1,024 | 0.021248 ms | 0.018064 ms | 1.18× | 58.047831 GB/s | PASS |
| 128 | 8,192 | 0.214640 ms | 0.167168 ms | 1.28× | 50.180703 GB/s | PASS |
| 4,096 | 128 | **0.213600 ms** | 0.222080 ms | **0.96×** | 18.886455 GB/s | PASS |
| 4,096 | 1,024 | 0.593984 ms | **0.426080 ms** | **1.39×** | **78.751485 GB/s** | PASS |
| 4,096 | 8,192 | 6.136608 ms | 5.111280 ms | 1.20× | 52.518246 GB/s | PASS |

`4×1003` 极端 logits 走标量回退，正确性通过，median 为 0.011840 ms。

向量化对 1K 和 8K 行长有明显收益，但 `cols=128` 略慢。原因是每行只有
32 个 `float4`，一个 warp 已能读完；当前仍启动 256 线程，其他 7 个 warp
只参与规约，没有承担元素工作。

## 3. Nsight Systems

`4096×1024` 的三个 kernel 实例 median 为 **0.422432 ms**，v1 为
0.596384 ms，对应 1.41× 加速，与独立 benchmark 一致。

## 4. Nsight Compute 对比

| 指标 | v1 | v2 | 变化 |
|---|---:|---:|---:|
| Memory throughput | 67.30% | **93.76%** | 接近 L2 上限 |
| Compute throughput | 49.45% | 40.95% | 相对占比下降 |
| Issue slots busy | 49.62% | 41.28% | 指令减少 |
| No eligible warp | 50.50% | 58.72% | 更内存受限 |
| L1TEX scoreboard stall | 12.8 cycles | 13.8 cycles | 近似 |
| Registers / thread | 23 | 32 | 四分量临时值增加 |
| Achieved occupancy | 97.12% | 95.32% | 基本不变 |
| Executed instructions | 9,297,920 | **5,611,520** | 下降 39.6% |

v2 的性能提升来自指令数下降和更高的内存吞吐；L2 throughput 达到 93.76%，
ncu 已提示可用内存性能超过 80%。主形状继续通过全局流量优化获得大幅收益会
比较困难。

## 5. 下一步

v3 不再修改主形状的数据路径，而是增加 shape-aware dispatch：

- `cols <= 128`：一个 warp 处理一行，一个 block 同时处理 8 行；
- `cols > 128`：保留 v2 的一个 block 处理一行。

这会解决短行中 7/8 warp 不承担元素工作的浪费，并验证“不同形状需要不同
并行粒度”，而不是寻找一个覆盖所有行长的单一配置。
